# Psychic Specters PC — development progress

Scope: European Yo-kai Watch 2: Psychic Specters, native Windows x64, from the owner's decrypted local cartridge. This project is independent of Super Mario 3D Land.

## Verified so far

- The original 4 GiB cartridge was read without modifying it. Title ID `00040000001B2900`, product `CTR-P-BYSP`. See `RECOMPILATION_STATUS.md`.
- The reference project uses Clockwork's AOT ARM/Thumb translator plus an adapted native service/graphics runtime, SDL3 and a portable Windows toolchain. Clockwork's own pinned MIT source already recognizes this specific Yo-kai title. We copied its unmodified translator, source runtime, documentation and license into `source/clockwork` and reused the pinned LLVM/Rust/CMake/SDL tool versions, without Mario-specific addresses or patches.
- 32,547 functions were translated to 96 C compilation units, then linked into `build/windows-x64/YoKaiWatch2.exe`, a 29,997,568-byte PE x86-64 executable. No external emulator or firmware is involved.
- Native Vulkan started successfully on the local NVIDIA RTX 3080 Ti. `tests/runs/boot-002` contains actual screenshots/logs of the opening cinematic, English title screen, touch New Game, diary selection, and gender selection.
- A first-launch test save directory is created successfully, isolated from any real player save.
- The opening story was played through character creation: gender selection, native touch keyboard entered `NATE`, confirmation, cinematic, bedroom, upstairs/downstairs movement and the conversation with Mom. `tests/runs/boot-002/bedroom_after_dialogue.png`, `downstairs.png` and `mom_dialogue.png` verify actual 3D exploration and dialogue.
- The Diary produced a successful save message and `game1.yw` (71,084 bytes) plus `head.yw` (21,844 bytes). A copy of this first isolated test save is retained in `tests/runs/fixtures/first-diary` for repeatable reload/benchmark tests.
- The RomFS inventory confirms seven original language archives `engb`, `fr`, `de`, `it`, `es`, `nl`, `ru`. All seven were started independently with the installed executable and checked visually at the localized title and New Game menu (`tests/runs/installed-language-*`); all exit codes were zero.
- A WPF launcher has been built (`dist/Launcher.exe`), reusing the reference's layout, 3DS control diagram, SDL controller capture and icon-conversion workflow with the supplied Jibanyan icon. The home, settings and controls previews render successfully (`tests/runs/launcher-preview/`).
- Portable command-line build tested on Windows PowerShell 5, including checksum validation and source-to-native linking. An isolated installation was produced at `tests/runs/build-validation/install`.
- Reloaded the first Diary and explored the house exit and Spring Breeze Boulevard. The scripted route reaches Dad in both the 30 and 60 FPS presentation modes.
- Added Vulkan resolution multipliers 1–10, window resolution presets through 4K/ultrawide and custom dimensions; genuine expanded horizontal and vertical camera ratios, with an 8192-pixel attachment safety limit. Tested ×5, ×6, ×8 and ×10 on the local GPU.
- Added stacked, side-by-side, priority, configurable inset and custom-position layouts; independent second-screen window with shared Vulkan device and selectable monitor. Verified actual separate-window rendering and swapping, hiding/restoring, aspect hotkeys and three-point touch-coordinate round trips.
- Prerecorded Y2R video conversions temporarily retain the native camera canvas instead of stretching their 400×240 pictures into the gameplay aspect; verified on the opening movie with 16:9 selected, and the title returns to the wider layout afterward.
- Improved Vulkan resource lifetime, bounded in-flight upload buffers, decoded HD texture cache and vertex worker profiles; accelerated ETC decoding with byte-exact scalar cross-check. Persistent known graphics-pipeline warmup and host frame-time measurements are implemented.
- Added WPF Display and Performance pages, GPU texture sampling options and a toggleable real presentation statistics overlay. Rendered all settings pages successfully.
- Added verified Diary export/import with staged copies, SHA-256 comparison and recovery backups. An isolated fixture export → import → backup preserved all three original files byte-for-byte; invalid empty import was rejected, and the imported Diary was loaded in the new game binary.
- Continued actual game progression through Dad's conversation, the car trip, Shopper's Row, Spirit/Soul decision, purchase of Spirit Doughnuts, the subsequent conversation with Mom and Dad, and the meeting with Bear and Eddie. Diary slot 1 saved successfully at Uptown - Triangle Way with the objective "Go home to get the Bug Net!" (`tests/runs/progress-ch2-001`, `tests/runs/fixtures/after-doughnuts`). The session ended normally after 29.29 minutes.
- Created a private, source-only Windows builder ZIP with the standalone launcher and verified extraction in a new folder containing spaces. A first build downloaded every pinned dependency, recompiled all 32,547 functions and linked independently; no ROM, generated game or saves were in the ZIP. A WPF build-flow self-test then returned to Ready to play after repairing inherited PowerShell module paths and using streamed .NET SHA-256 checks.
- Added named control profiles, cache reset/archive, log export and a diagnostic report that excludes cartridge paths and save contents. Tested their storage routines with separate fixtures. WPF input editor self-test verifies keyboard remap, independent controller mapping, reserved keys and virtual SDL controller input.
- Verified local mod load order, conflict reporting and profile restore with synthetic mods; the native runtime honors the configured order and disabled markers.
- Exercised the same window-to-touch mapper used by the mouse with actual title menu transitions to Diary selection in side-by-side, detached/swapped and inset layouts (`touch-mapped-*-2`), and opening the Diary in gameplay. All four runs exited normally.
- Verified a real Diary overwrite after reloading the Triangle Way checkpoint. The automatic pre-write backup matches the original fixture byte-for-byte; the secure-value checkpoint matches the newly saved files (`save-reload-checkpoint-2`).
- Recorded the original-rate audio stream and compared the same house/street route (Vulkan ×4, widescreen inset) in Original, 30 and 60 FPS. All three produced approximately 32728 DSP frames/s with no measured dropped frames, underruns or submission failures; the two capped modes stayed at 30.00 and 60.00 host presentations/s. See PERFORMANCE.md.
- Added optional Vulkan top-screen FXAA and adjustable sharpening with their own graphics pipeline. Both default off (original shader unchanged); four ×4 16:9 route runs with each setting and both combined displayed 60.00 FPS locally.
- Measured original/interpolated GPU image identities at presentation: in the ×1 and ×4 60 FPS house/street runs, approximately 59.50 and 59.58 newly rendered top images were shown per second, including 29.71 midpoints/sec. Unlike a present-rate counter, these tags distinguish repeated GPU images. See PERFORMANCE.md.
- Added actual Windows per-process GPU local/nonlocal memory telemetry, with a separately labeled fallback for tracked texture payload. Tested the local two-matching-adapter case and both ×1/30 and ×4/60 routes. The launcher also enumerates actual SDL playback devices and persists a selected device; an isolated WPF test saved and reloaded all custom graphics, aspect, window, inset, audio and FXAA settings in both launcher and installed game settings.
- Fixed the map-streaming allocation failure at Triangle Way (terrain block 56). The same issue affected rendering and collisions: the original 1.25 MiB heap could not allocate a 70,380-byte mesh at index 42. The native build now allocates four 4 MiB blocks within a 35.5 MiB map parent; the original 3DS allocator and all other heap budgets remain in use. The complete read-only map audit checked 2,208 files, 106,963 archive entries, 29,376 mesh streams/objects, 4,472 images and 127,375 compressed streams without errors. The largest conservative streamed-tile estimate is 1,657,480 bytes, and the largest base-region estimate (including alternative assets) is 17,520,048 bytes, below the corresponding revised budgets. Scripted crossings and school exploration loaded the existing terrain chunks without failure. The original route's largest grey region reached 32.93%; the corrected ×4/60 route measured 0% including the original failure point, and the player remained on the road. See `tests/verify-map-memory.ps1` for reproducible checks.
