# Known issues and verification gaps

- This is an early native development build, not a finished release. Startup, character creation, opening, first house exploration/dialogue, Shopper's Row and the Spirit Doughnuts sequence through Triangle Way have been verified; a real Diary overwrite and its recoverable checkpoints were checked. Later gameplay remains to test.
- The upstream runtime recognizes the European title, but individual quest, battle, save/reload and postgame behavior require testing in this port.
- All seven original languages now display their localized title and New Game menu. Later dialogue, fonts and every localized game screen remain to verify.
- The first boot logs unknown CFG defaults (`00130000`, `00030001`) returning zero. Investigate against real behavior; they did not prevent displaying the tested menu.
- Cold GPU pipeline compilation can cause visible spikes (124.6 ms in the first boot; additional cold keys can stall). Known pipeline states are now prewarmed from a persistent driver/shader-specific list; this does not eliminate all first-time compilation. See PERFORMANCE.md for controlled frametimes.
- External game mod downloads and upstream automatic updates are disabled in the initial standalone build; local mods and texture replacement runtime are retained. This prevents installation of an unrelated upstream executable. Network features and mods still require validation.
- True widened or taller camera views are experimental outside the tested house/street; ultrawide exposes scenery edges. The opening prerecorded Y2R video retains its original aspect, while gameplay automatically resumes the selected aspect. Other cinematic/HUD elements still need broader verification; extreme 32:9 ×10 is limited by the attachment size (effective ×9). Software fallback is limited to ×4 and horizontal expansion.
- Separate windows were tested on the single available physical display; real multi-monitor/VRR and GPU vendor compatibility remain unverified.
- The 60 FPS mode interpolates suitable scenes, not native 60 Hz game logic; unmatched transitions may repeat original images. Sound synchronization, sustained memory and full progression remain unverified.
- The specific terrain-streaming heap exhaustion causing missing ground and fall-through at Triangle Way is fixed. All map archives have passed structural/model/image decompression checks. This does not replace real scene-by-scene tests of the later maps, collision semantics, quests and effects.
